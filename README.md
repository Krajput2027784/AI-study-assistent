# AI Study Assistant

A production-ready SaaS learning assistant built with React/Vite, FastAPI, SQLite, and Google Gemini.

## Highlights
- 🧠 **Google Gemini 3.6 Flash Integration** for AI Study Chat & Quiz Generation
- 📄 **Document Intelligence** (PDF, Markdown, TXT) with contextual Q&A
- 📝 **Smart Notes & AI Study Guide Enhancer**
- 🎯 **Interactive Quizzes** with automated grading, explanations, and review
- 🎧 **Multimedia Resources** (Audio/Video uploads & YouTube embeds)
- 📊 **Progress Dashboard** with aggregated study statistics
- 🔒 **JWT Auth & CORS Security** with production-grade validations
